English
Effective date: October 11, 2026
The Easy Gaming bot (the "Bot") stores Discord user IDs and moderation history for the servers of the Easy Gaming project. It does not store the text of messages.

1. Data we store
   • Discord user IDs and server IDs.
   • Moderation history: warnings, timeouts (mutes), kicks and bans, with the date, the reason and the moderator who took the action.
   • Technical logs needed to run the Bot and investigate errors.
2. Data we do not store
   The Bot reads message content in real time in order to moderate, but it does not save the text of messages.
3. Why we use this data
   We use it only to moderate Easy Gaming servers: to enforce server rules, keep track of repeat violations and review appeals.
4. Who has access
   Only the Easy Gaming project team and the moderators of its servers. We do not sell this data and do not share it with third parties, except where the law requires it.
5. How long we keep it
   Moderation history is kept indefinitely, so that repeat violations can be taken into account. You can ask us to delete your data at any time (section 6).
6. Your rights
   You can ask what data the Bot holds about you, and ask us to correct or delete it. Write to sashashtal@gmail.com and include your Discord user ID. We respond within 30 days.
7. Security
   The data is stored on servers that only the project team can access.
8. Children
   The Bot is not intended for people below the minimum age set by the Discord Terms of Service.
9. Changes
   We may update this policy. The current version is always published on this page.
10. Contact
    Questions and data requests: sashashtal@gmail.com
    Русский
    Дата вступления в силу: 11 октября 2026 г.
    Бот Easy Gaming (далее «Бот») хранит ID пользователей Discord и историю модерации на серверах проекта Easy Gaming. Тексты сообщений он не хранит.
11. Какие данные мы храним
    • ID пользователей и ID серверов Discord.
    • История модерации: предупреждения, тайм-ауты (муты), кики и баны с датой, причиной и модератором, который выдал наказание.
    • Технические логи, необходимые для работы Бота и разбора ошибок.
12. Какие данные мы не храним
    Бот читает содержимое сообщений в реальном времени, чтобы выполнять модерацию, но не сохраняет тексты сообщений.
13. Зачем нужны эти данные
    Мы используем их только для модерации серверов Easy Gaming: чтобы следить за соблюдением правил, учитывать повторные нарушения и рассматривать апелляции.
14. Кто имеет доступ
    Только команда проекта Easy Gaming и модераторы его серверов. Мы не продаём эти данные и не передаём их третьим лицам, кроме случаев, когда этого требует закон.
15. Как долго хранятся данные
    История модерации хранится бессрочно, чтобы можно было учитывать повторные нарушения. Вы можете в любой момент запросить удаление своих данных (раздел 6).
16. Ваши права
    Вы можете узнать, какие данные о вас хранит Бот, и попросить исправить или удалить их. Напишите на sashashtal@gmail.com и укажите свой ID пользователя Discord. Мы отвечаем в течение 30 дней.
17. Безопасность
    Данные хранятся на серверах, доступ к которым есть только у команды проекта.
18. Дети
    Бот не предназначен для людей младше минимального возраста, установленного Условиями использования Discord.
19. Изменения
    Мы можем обновлять эту политику. Актуальная версия всегда опубликована на этой странице.
20. Контакты
    Вопросы и запросы о данных: sashashtal@gmail.com
